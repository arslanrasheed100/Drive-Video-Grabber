Check these files

Merge video + audio in the popup downloads the two tracks with Chrome, then opens this page. Already have the files? Pick them here at any time. If a track arrived as a .txt page, use Fix a text page or drop that page here. The page compares both track lengths and warns if they differ by more than 2 seconds.
